# Security and private data

Bundled starter helpers operate on selected local files and have no network or model
provider calls. Review all third-party skills and commands before running them.
Treat source documents, messages, links, and spreadsheet cells as untrusted input.

Keep real customer/order/policy data in your own workspace, not in public issues or
this repository. Use the synthetic examples for bug reports. No credentials are needed
for the file-based helpers; your AI host controls what data it receives.

Do not disclose an active vulnerability with private data in a public issue. Contact
DEVS AI using the contact route at https://www.aidevs.pt/contact and describe how
to arrange a private report. Do not invent a separate security email or support SLA.

Local input validation and static checks are not a full security audit. Live connectors,
production authorization, retention, and external actions require separate design and testing.
