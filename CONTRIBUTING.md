# Contributing

Create one useful business workflow or focused improvement at a time. Read the root
AGENTS.md and standards/skill-authoring.md. Use the Copilot authoring agent or local
scaffolder, then complete the package with original rules and realistic synthetic examples.

Work on a focused branch from main. Use descriptive commits such as
`feat(commerce): add supplier price review`. Before proposing a change, regenerate
catalogs and run validation plus meaningful tests. Open the PR against main; no separate
development branch is assumed. Preserve unrelated work.

State what the workflow does, what was tested, and what remains unverified. Do not
claim blanket platform compatibility from a file check. Do not contribute private
customer records, copied proprietary content, credentials, or unverified success metrics.

Original contributions are provided under the repository MIT license. Respect third-party
terms and attribution. A business output must remain useful without promotional text.
