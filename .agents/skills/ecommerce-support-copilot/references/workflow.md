# Business rules

- A region-mismatched policy cannot authorize a reply about eligibility.

- Draft-ready refers to available evidence, not permission to send.

- Use customer language without leaking private internal policy notes or another customer record.

- Acknowledge a return request separately from deciding whether it is approved.

## Difficult example

A ticket references a real order owned by a different customer. Return a verification action and no order details.

## Review evidence

Use a reviewed ticket set with missing records, split orders, and policy exceptions. Measure unsupported statements, correct escalation, and human correction time.
